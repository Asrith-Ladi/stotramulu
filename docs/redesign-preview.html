స్తోత్రములు — కొత్త రూపం (ప్రివ్యూ)

Proposed direction: "Kanchi silk". The chrome uses deep peacock teal, like a traditional Kanchipuram pattu body. Zari gold marks accents and borders, kumkum red appears only as small signals, and the reading surface is calm ivory paper. It's cool and soothing, still clearly traditional, and nothing like Poshana's warm cream. These are static mockups at real phone size (390px). The live site hasn't changed.

What the preview shows (desktop gets the same system, with the tabs moved into the top header):

  • A fixed bottom menu on phones: 4 big tabs with Telugu labels. It's always in the same place, so nothing has to be hunted for.
  • A compact top bar: a "What's new" bell (a red dot means something new), search, and account.
  • ⓘ buttons next to each feature. Tapping one opens a short plain-Telugu explanation with an English line underneath.
  • Account becomes a single help hub: Google sign-in first, "report a problem", "My messages" with a status for each message (New / In progress / Answered), "What's new", and file backup last.
  • Motion stays gentle: sheets slide up, cards fade in one after another, buttons press in. All of it turns off if the phone asks for reduced motion.
