# Stotramulu

Telugu devotional reading site, with a Cloudflare worker in `src/` and static assets in `public/`.

- [Content audit and source considerations](docs/CONTENT-AUDIT.md)
- [Implemented UI/UX improvements and next steps](docs/UX-PLAN.md)
- Run checks: `node tools/verify.cjs`
- Inventory: `node tools/audit-stotras.cjs`

The September 2026 audit restores Lalitha's main 183-verse text and Suprabhatam's 29 verses. Other editions are explicitly flagged where source review is unresolved. Meaning review and mobile visual QA remain pending; see the reports for the precise scope.
